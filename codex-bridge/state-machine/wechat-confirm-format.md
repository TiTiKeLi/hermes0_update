# WeChat 确认界面设计

## 确认消息格式

Hermes 在 WeChat 上向用户发送确认时，必须使用以下格式：

```
━━━ 需要确认 ━━━
请求: {请求摘要}

请回复:
【1】确认执行
【2】拒绝
【3】稍后再说（30分钟内有效）
────────────────
回复数字即可
```

## 示例

```
━━━ 需要确认 ━━━
请求: 磁盘使用率 82%，是否执行清理？

请回复:
【1】确认执行
【2】拒绝
【3】稍后再说（30分钟内有效）
────────────────
回复数字即可
```

## 参数输入格式

需要用户输入参数时：

```
━━━ 需要确认 ━━━
请求: 需要 GitHub Token 以访问私有仓库

请回复:
【1】提供 Token: <你的 Token>
【2】拒绝授权
────────────────
回复【1 你的token】或【2】
```
