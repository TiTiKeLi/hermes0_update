# 确认界面格式（WeChat）

## 规范

所有推送给用户的确认消息必须使用此格式，全中文。

## 标准确认格式

```
━━━ 需要确认 ━━━
<<请求摘要。用一段话说明，不要多段。>>

请回复：
【1】<<选项1描述>>
【2】<<选项2描述>>
【3】<<选项3描述>>（可选）
────────────────
回复数字即可
```

## 带参数的确认格式

```
━━━ 需要确认 ━━━
<<请求摘要>>

请回复：
【1】提供: <<参数说明>>
【2】拒绝
────────────────
回复【1 你的值】或【2】
```
