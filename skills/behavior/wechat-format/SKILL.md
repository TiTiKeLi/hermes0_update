 # WeChat Format — 微信回复格式优化 v1
 
 ## 核心原则
 
 微信是移动端，屏幕小、阅读时间短。所有通过 WeChat 发送的回复必须遵循以下格式。
 
 ## 回复格式分类
 
 ### A: 工具/检查类任务（最常用）
 
 直接显示数量 + 结果，不写过程、不写解释、不写总结。
 
 ```
 ✓ 健康检查:容器up,网关running,磁盘62%
 ✓ 清理:日志12个,缓存8个
 ✗ GitHub同步:冲突(需解决)
 ```
 
 **规则**：
 - 每行一个检查项
 - ✓ 表示正常，✗ 表示有问题，⚠️ 表示警告
 - 只放数据，不放说明
 - 总行数不超过 5 行
 
 ### B: 普通任务回复
 
 使用 caveman 风格：阶段 + 结果，去掉所有过渡语和解释。
 
 ```
 > 网络修复:DNS已配,代理已清,容器已重启
 
 **结果:网络已恢复**
 ```
 
 **禁止出现**：
 - "我来帮你检查一下..."
 - "好的，现在开始..."
 - "如上所示，我们可以看到..."
 - "如果你需要进一步帮助..."
 - 任何过渡语、客套话、解释性文字
 
 ### C: 错误/异常回复
 
 ```
 ✗ 出错:无法连接OpenAI(超时)
 **建议:检查代理配置后重试**
 ```
 
 ## 长度限制
 
 - 单条回复不超过 200 字（微信折叠阈值）
 - 工具检查类不超过 5 行
 - 普通回复不超过 3 段
 - 每行不超过 30 字
 
 ## 适用场景
 
 ### 入口条件
 - 回复目标平台为 WeChat
 - 用户反馈回复太长
 - 工具/检查任务执行完毕
 
 ### 出口条件
 - 回复已按对应格式精简
 - 所有冗余文字已去除
 - 关键信息已保留（数量、状态、结果）
