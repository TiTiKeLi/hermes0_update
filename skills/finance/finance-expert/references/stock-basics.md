## 基础概念

### 什么是股票
股票 = 公司的**所有权凭证**。买股票 = 成为公司的小股东。

### 关键术语

**价格类**
- **开盘价**：9:30 第一笔成交价
- **收盘价**：15:00 最后一笔成交价
- **最高/最低**：当天价格极值
- **昨收**：上一个交易日的收盘价
- **涨跌幅**：(当前价 - 昨收) / 昨收 × 100%

**量类**
- **成交量**：成交的股票数量（手，1手=100股）
- **成交额**：成交的总金额
- **换手率**：当天成交股数/总股本。高换手=交易活跃

**估值类**
- **PE（市盈率）** = 股价 / 每股收益。**越低越便宜**
  - PE<10: 低估；10-20: 合理；20-30: 偏高；>50: 泡沫或高成长
- **PB（市净率）** = 股价 / 每股净资产。**破净=低于净资产**
  - PB<1: 破净（价格低于净资产）；1-3: 正常；>5: 溢价高
- **股息率** = 每股分红 / 股价。**越高越好**

## A股基本规则

| 规则 | 详情 |
|------|------|
| 交易时间 | 9:30-11:30, 13:00-15:00 |
| 竞价阶段 | 9:15-9:25 集合竞价 |

| 涨跌幅限制 | 主板±10%, 创业板/科创板±20% |

| 停牌规则 | 异常波动可临时停牌 |

## K线基础

```
K线 = 单位时间内的价格四要素
    开 ── 最高
    │    收盘（涨=红/绿，跌=绿/蓝）
    收 ── 最低
```

**常见形态：**
- **阳线**（涨）：收盘 > 开盘，实体越大涨势越强
- **阴线**（跌）：收盘 < 开盘，实体越大跌势越强
- **十字星**：开收接近，多空均衡
- **下影线**：先跌后涨，有支撑
- **上影线**：先涨后跌，有压力

## 常见术语

| 术语 | 解释 |
|------|------|
| 多头/看多 | 认为要涨 |
| 空头/看空 | 认为要跌 |
| 仓位 | 投入资金占总资金的比例 |
| 满仓 | 全部资金买入 |
| 轻仓 | 少量仓位 |
| 建仓 | 买入建立仓位 |
| 平仓/清仓 | 全部卖出 |
| 加仓 | 继续买入 |
| 减仓 | 部分卖出 |
| 割肉 | 亏损卖出 |
| 踏空 | 涨了没买 |
| 套牢 | 跌了没卖 |
| 主升浪 | 涨势最猛的阶段 |
| 缩量/放量 | 成交量减少/增加 |
| 北向资金 | 外资通过港股通买入A股 |
| 南向资金 | 内资买入港股 |
