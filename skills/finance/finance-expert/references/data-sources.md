## 腾讯财经 API (`qt.gtimg.cn`)

**稳定度**: ✅ 高（持续运行，几乎不限频）

**支持范围**:
| 市场 | 实时行情 | 日K线历史 | 周K线 |
|------|:--------:|:---------:|:-----:|
| A股 (上证/深证) | ✅ | ✅ 完整 | ✅ 周线 |
| 港股 (hk前缀) | ✅ | ✅ | ✅ |
| 美股 (us前缀) | ✅ | ❌ **仅1天** | ❌ |

**⚠️ 美股历史数据只有当天1条K线**，无法用于回测。这是腾讯API的已知限制，不是bug。

**常用代码示例**:
```
sh000001  - 上证综指
sh000300  - 沪深300
sh000016  - 上证50
sz399006  - 创业板指
hkHSI     - 恒生指数
usINX     - 标普500
usDJI     - 道琼斯
usIXIC    - 纳斯达克
```

**编码**: 返回 GBK 编码，需 `resp.read().decode("gbk")`

## Yahoo Finance API (`query1.finance.yahoo.com/v8/finance/chart/`)

**稳定度**: ✅ 中高（可能有频率限制，但容错可）

**支持范围**: 美股全量历史日K线

**⚠️ 容内需要联网检查**: 有时延迟到 4-8s，需要 timeout=15 以上

**⚠️ 数据结构复杂**: results[0].indicators.quote[0].close 这种嵌套结构提取

---

## 新浪财经 API (`hq.sinajs.cn`)

**稳定度**: ⚠️ 中等（格式不统一）

**格式**: GBK 编码，行列分隔符不标准

**⚠️ 不建议作为主力**: 作为腾讯API的备用源。

## 东方财富新闻 API

**稳定度**: ❌ 低频控（快速变动，多次测试失败）

**结论**: 不要作为主力新闻源，优先使用新浪财经滚动新闻。

## 回测引擎局限

**backtest.py 已知限制**:
1. **仅A股/港股有完整历史** — 美股代码传进去只能拿到1天数据，回测无意义
2. **无numpy/statsmodels** — 容器环境没有这些库，标准差/协方差需手动计算
3. **历史bug**: `max(returns).std()` 报错 — `max()` 返回float, 没有 `.std()` 方法
   - 正确做法: 手动计算均值和方差 `sum((r - mean)**2 for r in returns) / len(returns) ** 0.5`
4. **只支持日线** — 暂不支持分钟级/周级回测
5. **简单策略只内置了MA金叉死叉** — 扩展策略需在 `strategy_ma()` 函数底部添加

---

## 新闻源局限

**新浪财经 (`feed.mix.sina.com.cn`)**:
- 速度快，稳定
- 返回 `ctime` 字段是 Unix 时间戳（不是格式化日期）
- 用 `time[:10]` 只能显示时间戳戳，不是可读日期

**正确格式化**: `import datetime; datetime.datetime.fromtimestamp(int(n['time'])).strftime('%m-%d %H:%M')`
