## 核心理念

技术分析的三大假设：
1. **市场行为包容一切** — 所有信息已反映在价格中
2. **价格沿趋势移动** — 趋势一旦形成，会持续
3. **历史会重演** — 人性不变，模式不变

> ⚠️ 注意：技术分析是**辅助工具**，不是预测水晶球。

## 均线系统（最基础也最重要）

### 常用均线
- **MA5**：5日均线 = 一周均价。短线生命线
- **MA10**：10日均线 = 两周。短线支撑
- **MA20/MA30**：月线。中线趋势
- **MA60**：季线。多空分水岭
- **MA120/MA250**：半年/年线。牛熊分界线

### 均线用法

**多头排列**：短期均线在长期均线上方 → 上涨趋势 ✅
**空头排列**：短期均线在长期均线下方 → 下跌趋势 ❌
**金叉**：短期均线上穿长期均线 → 买入信号
**死叉**：短期均线下穿长期均线 → 卖出信号

## 常见技术指标

### MACD
- **DIF**：快线 - 慢线
- **DEA**：DIF的均线
- **柱状图**：DIF - DEA
- 金叉（DIF上穿DEA）→ 买入
- 死叉（DIF下穿DEA）→ 卖出
- 顶背离（价格新高但MACD没新高）→ 见顶⚠️
- 底背离（价格新低但MACD没新低）→ 见底✅

### KDJ（随机指标）
- K值 > 80 → 超买（可能跌）
- K值 < 20 → 超卖（可能涨）
- 金叉/死叉用法和均线类似

### RSI（相对强弱指标）
- RSI > 70 → 超买
- RSI < 30 → 超卖
- 常用周期：6日、14日

### BOLL（布林带）
- 中轨 = MA20
- 上轨 = MA20 + 2倍标准差
- 下轨 = MA20 - 2倍标准差
- 价格触上轨 → 压力位
- 价格触下轨 → 支撑位
- 收窄(缩口) → 即将变盘
- 开口扩大 → 趋势加速

## 量价关系

| 情况 | 含义 |
|------|------|
| 上涨 + 放量 | ✅ 强势，资金涌入 |
| 上涨 + 缩量 | ⚠️ 上涨乏力 |
| 下跌 + 放量 | ⚠️ 恐慌出逃 |
| 下跌 + 缩量 | ✅ 抛压减弱，可能见底 |
| 横盘 + 缩量 | 等待方向选择 |
| 横盘 + 放量 | 多空分歧大 |
| 突破 + 放量 | ✅ 有效突破 |
| 突破 + 缩量 | ⚠️ 假突破 |

### 反转形态
| 形态 | 位置 | 信号 |
|------|------|------|
| 锤子线 | 下跌后 | 见底✅ |
| 射击之星 | 上涨后 | 见顶⚠️ |
| 头肩顶 | 上涨后 | 见顶⚠️ |

| 双重顶(M顶) | 上涨后 | 见顶⚠️ |
| 双重底(W底) | 下跌后 | 见底✅ |

### 持续形态
| 形态 | 说明 |
|------|------|
| 旗形 | 短暂休整后继续原方向 |
| 三角整理 | 震荡区间逐步收窄 |
| 矩形 | 横盘震荡 |

## 支撑与压力

- **支撑位**：技术上"应该"止跌的位置
  - 前低
  - 均线（MA20/MA60）
  - 黄金分割位（0.382/0.5/0.618）
- **压力位**：技术上"应该"遇阻的位置
  - 前高
  - 均线
  - 整数关口（3000点/50000点）

**突破原则**：
- 突破压力+放量+站稳3天 = 有效突破
- 跌破支撑+放量+3天不收回 = 有效跌破

## 一句话

> 技术分析 = 概率游戏，不是预言。用做辅助决策，不是全仓押注的依据。
