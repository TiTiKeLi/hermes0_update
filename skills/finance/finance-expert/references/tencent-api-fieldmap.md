# 腾讯API (qt.gtimg.cn) 字段映射表 v1
## 2026-07-26 实测确认

## 基础信息
- **接口**: `https://qt.gtimg.cn/q=<股票代码>`
- **编码**: GBK (resp.read().decode('gbk'))
- **格式**: `v_<代码>="<f1>~<f2>~...~<fN>";`
- **前缀**: `sh`(上证) / `sz`(深证) / `hk`(港股) / `us`(美股)

## ⚠️ 已知陷阱

### 索引漂移风险
所有索引都依赖腾讯API的返回顺序。如果腾讯API升级（增减字段），所有索引会偏移。**每次使用时先用测试脚本验证关键字段**。

### 验证方法
```python
import urllib.request
url = 'https://qt.gtimg.cn/q=sh600519'
resp = urllib.request.urlopen(urllib.request.Request(url), timeout=8)
raw = resp.read().decode('gbk')
parts = raw.strip().split('=',1)[1].strip(';').strip('"').split('~')
for i in range(35, 70):
    print(f'parts[{i}] = {parts[i]!r}')
```

### 行业字段
parts[57] 返回的是行业指数代码(如462224=白酒板块)，不是行业名称。行业名应在58-65区间内查找。

### 市值单位
茅台约12.56亿股×1297元≈1.63万亿。
- 若parts[45]≈1620000000000 → 单位是**元**
- 若parts[45]≈16292388 → 单位是**万**（但数值对不上）
- 需实测确认
