## 什么是ETF

**ETF (Exchange Traded Fund)** = 交易所交易基金。本质上是一个**可以在股票市场买卖的指数基金**。

好比你去超市买"水果拼盘"而不是一个一个挑苹果香蕉橙子。

### ETF vs 股票 vs 普通基金

| | 个股 | ETF | 普通基金 |
|--|------|-----|---------|
| 买什么 | 一家公司 | 一篮子资产 | 看基金经理操作 |
| 费用 | 佣金 | 佣金+管理费(极低) | 管理费(高) |
| 分散风险 | ❌ 集中 | ✅ 分散 | ✅ 分散 |
| 实时交易 | ✅ | ✅ | ❌ 每天一次净值 |
| 门槛 | 1手(100股) | 1手(100份) | 通常10元起 |

## 为什么要买ETF

1. **分散风险** — 买1个ETF=买了一篮子几十上百只股票
2. **费用极低** — 管理费0.15-0.5%/年 vs 主动基金1-2%
3. **操作简单** — 像买股票一样买卖
4. **透明度高** — 每天公布持仓，没有"黑箱操作"
5. **适合定投** — 每月固定金额买入，摊平成本
6. **规模优势** — 机构资金主要配置方向

## ETF投资策略

### 定投策略（最简单）
```
每月固定日期买入固定金额的宽基ETF
不管涨跌，坚持执行
核心：长期持有，10年+
```

### 网格交易（震荡市）
```
在震荡区间内：跌X%买入，涨X%卖出
适合波动大的ETF（如创业板、科技、证券）
不适合单边牛市（会卖飞）
```

### 股债平衡（最经典）
```
50% 股票ETF + 50% 债券ETF
每年再平衡一次：卖高买低
风险收益比最优
```

## ETF核心指标

| 指标 | 含义 | 怎么看 |
|------|------|--------|
| 净值 | 每份的实际价值 | 不太偏离市价即可 |
| 折溢价 | 市价比净值高/低 | 溢价>1%不买，折价>1%可留意 |
| 规模 | 基金总资产 | 越大越好（流动性好） |
| 日均成交额 | 每天交易量 | >1亿的流动性较好 |
| 跟踪误差 | 和指数差距 | 越小越好（<0.5%/年） |

## 新手避坑

❌ **溢价太高不买** — 有些QDII ETF溢价高达5-10%，等于多花了冤枉钱
❌ **频繁交易** — ETF不是股票，别短炒
❌ **买小规模ETF** — <2亿规模的ETF有清盘风险
✅ **优先选规模大、成交活跃的** — 龙头ETF（如沪深300选510300）
✅ **定投+长期持有** — ETF最适合的方式
