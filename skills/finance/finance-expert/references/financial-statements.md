## 财报三张表

### 1. 利润表（公司赚了多少）

```
收入 - 成本 = 毛利
毛利 - 费用 = 营业利润
营业利润 + 其他 - 税 = 净利润
```

**关键指标：**
- **营业收入**：卖了多少东西。持续增长=好
- **毛利率** = (收入-成本)/收入。>40%=好生意
- **净利率** = 净利润/收入。>15%=盈利能力强
- **ROE** = 净利润/股东权益。**最重要指标**。>15%=优秀

### 2. 资产负债表（公司有什么、欠什么）

```
资产 = 负债 + 股东权益
```

**关键指标：**
- **资产负债率** = 总负债/总资产。<50%正常，<30%稳健
- **流动比率** = 流动资产/流动负债。>1.5安全
- **存货周转率**：存货卖得越快越好
- **应收帐款**：别人欠公司的钱。越少越好

### 3. 现金流量表（真实现金进出）

**分为三类：**
- **经营活动现金流**：做生意赚的钱。**必须为正**，且>净利润最好
- **投资活动现金流**：买设备/投资的钱。一般为负（正常）
- **筹资活动现金流**：借钱/分红的钱

**最重要：经营活动现金流。** 利润可以造假，现金造不了假。

## 快速排雷清单

| 危险信号 | 说明 |
|---------|------|
| 净利润增长但经营现金流为负 | ⚠️ 利润可能是假的 |
| 应收账款暴增 | ⚠️ 东西卖出去了但收不到钱 |
| 毛利率骤降 | ⚠️ 竞争加剧/成本失控 |
| 大额商誉 | ⚠️ 收购溢价太高，可能暴雷 |
| 大股东减持 | ⚠️ 自己人都不看好 |
| 财务费用异常高 | ⚠️ 借了太多钱 |
| 审计意见"非标" | ⚠️ 会计师不认可 |
| PE极高但没利润 | ⚠️ 纯炒作 |

## 三步扫完一份财报

> **10分钟筛查法**（不用一字一句读）

**Step 1: 看收入+利润（1分钟）**
- 收入在增长吗？
- 毛利率稳定或提升吗？
- 净利润率多少？

**Step 2: 看现金流（2分钟）**
- 经营现金流 > 净利润 = 利润真实
- 经营现金流为负 = 危险

**Step 3: 看资产负债表（3分钟）**
- 负债率合理吗？
- 有隐蔽风险吗？（商誉、担保、关联交易）

## 行业特殊指标

| 行业 | 特殊指标 | 说明 |
|------|---------|------|
| **银行** | 不良率、拨备覆盖率、净息差 | 关注坏账 |
| **保险** | 新业务价值、内含价值、偿付能力 | 长期保单 |
| **地产** | 土储、资产负债率、销售面积 | 杠杆最高 |
| **科技** | 研发费用率、用户数、ARPU | 成长优先 |
| **消费** | 同店增长、客单价、复购率 | 品牌力 |
| **医药** | 研发管线、专利到期、集采影响 | 政策敏感 |
| **资源** | 储量、产能利用率、商品价格 | 周期股 |

## 估值vs财报结合

```
高ROE + 低PE = 可买
高ROE + 高PE = 好公司但贵了
低ROE + 低PE = 便宜但赚钱能力差
低ROE + 高PE = ❌ 最危险
```

## 经典案例

**好公司特征：**
- 过去5年ROE > 15%
- 经营现金流 > 净利润
- 营收+利润同步增长
- 负债 < 50%，有现金储备
- 毛利率稳定提升
