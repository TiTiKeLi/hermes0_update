## 回测参数

```
标的代码:        (如 sh000300 / usSPY / 510300)
标的名称:        (如 沪深300 / S&P 500)
策略名称:        (均线策略 / 定投 / 自定义)
策略参数:        (如 MA5,MA20)

买入条件:
  条件1: 
  条件2: 

卖出条件:
  条件1:
  条件2:
  止损线: ___% （可选）

回测周期:
  开始日期:
  结束日期:

初始资金: 100000 元
手续费率: 0.03%
```

## 策略类型参考

| 策略 | 说明 | 适合 |
|------|------|------|
| MA金叉死叉 | 快线上穿慢线买入，下穿卖出 | 趋势行情 |
| 定投 | 固定金额/固定时间买入 | 长期持有 |
| 网格交易 | 区间震荡高抛低吸 | 震荡市 |
| 股债平衡 | 股票ETF+债券ETF定期再平衡 | 长期稳健 |
| 价值平均 | 保证账户每月增长固定金额 | 有计划的投资 |
